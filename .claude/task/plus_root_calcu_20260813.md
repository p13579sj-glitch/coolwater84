# Task CALC-001 - 계산기 프로그램에 루트(제곱근) 계산 기능 추가

> 설계 검증용 샘플 요구사항 문서다. spec.md §5(요구사항 문서)에서 정의한 형식을 실제로 작성해보고, main agent가 사전검토 → 개발 → 리뷰 → 기록 루프에서 이 문서를 근거로 삼아 동작하는지 검증하는 목적이다.

## 한 줄 요약

기존 계산기 프로그램에 루트(√, 제곱근) 계산 기능을 추가한다.

## 요구사항 상세

- **배경**: 계산기 프로그램이 현재 사칙연산(+, -, ×, ÷)만 지원한다고 가정한다. 이 자동화 프로세스(요구사항 문서 → RULES.md 준수 → review-checker 리뷰 → task-recorder 기록)가 작은 규모의 실제 기능 변경에도 정상 동작하는지 확인하기 위한 설계 검증 Task다.
- **무엇을**: 계산기에 루트 계산(√x) 입력/버튼을 추가하고, 입력값 x에 대한 제곱근을 계산해 결과를 반환한다.
- **왜**: 요구사항 문서 → 리뷰 → 기록으로 이어지는 Task 루프 전체가 실제로 작동하는지 파일럿으로 검증하기 위함(RVW-011과 연결되는 설계 검증 샘플).

## 완료 기준 (Acceptance Criteria)

- [ ] 계산기에 루트 계산 입력/버튼이 추가된다.
- [ ] 0 이상의 입력값에 대해 정확한 제곱근 값을 반환한다.
- [ ] 음수 입력 시 예외 또는 명확한 오류 메시지를 반환하고, 실수 범위를 벗어난 결과(NaN 등)를 그대로 노출하지 않는다.
- [ ] 기존 사칙연산 기능에 회귀(regression)가 없다.

## 영향 범위

- **핵심 클래스(예상)**: 계산 로직을 담당하는 클래스/모듈(예: `Calculator`). 실제 대상 프로젝트가 지정되지 않은 설계 검증 단계라 구체적 파일 경로는 미정 — 사전검토 단계에서 대상 프로젝트 구조 확인 후 채운다.
- **핵심 클래스 외 예상 영역**: UI(버튼/입력 레이아웃) 변경이 필요하다면 별도 표시 필요.
- **변경 파일 수 상한**: 미합의 (사전검토 단계에서 엔지니어와 확정)
